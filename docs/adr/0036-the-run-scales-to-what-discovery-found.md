# The run scales to what discovery found

Maestro applied every step to every run: the codex second opinion, a fresh reviewer per builder, the full QA loop, identical for a one-file repair and a feature. The run for nadicodeai #623 knew the work was "the smallest fix of the lot" from its own triage and had nowhere to put that knowledge. Proportionality mechanisms existed six times in this repo's history and the last one, phase choice by reversal cost (ADR 0027), was deleted as collateral in the 0.129.0 rewrite (ADR 0033): once the committed spec and plan documents were gone, a phase whose only job was deciding whether to write them had nothing left to decide. The steps that remained, the second opinion and the reviewers, were still worth sizing, and nothing sized them.

Decision. After discovery, maestro tells the owner how much of the rest the work needs and runs only that. A step is skipped when nothing in it is still unclear and a wrong call there is cheap to undo after the merge. Four things never get skipped: the worktree and branch, the gates green, the review of the whole diff, and the PR. The call is reversible: work that turns out bigger re-enters the step it skipped. Two site-local consequences are written where the dispatch happens, because a condition three paragraphs away loses to the sentence in front of the agent: the second opinion runs when a bad design would hurt to undo and is skipped out loud otherwise, and a single-builder run skips the per-builder reviewer because the integrated review reads the identical diff minutes later.

The test is reversal cost, never size. ADR 0027's lab runs showed size is the signal a model reaches for unprompted and the wrong one, and the #623 run confirmed it live in both directions: the "smallest fix" grew a silent-wrongness discovery and a design hole, while the machinery it actually needed was decided by what a wrong call cost to undo.

Evidence before landing: the edited skill was dry-run by two orchestrator agents against real issues (nadicodeai #401 and #612). Both made the call, scaled correctly in opposite directions, and their counterfactuals confirmed each sentence changes a real dispatch decision: without them, one would have sent a codex read and a duplicate reviewer at four sentences of copy, the other would have added a QA drive whose only output re-screenshots a page an existing test asserts.

The trade-off booked honestly, inherited from ADR 0027: reversal cost is a judgment call where the old tests were mechanical, so maestro can under-call a risky change. The counterweights: the call is said to the owner before it acts, the four fixed things stand regardless, and the go-back rule re-enters skipped steps when the work outgrows the call.

Restores ADR 0027's test into ADR 0033's one simple flow. ADR 0033 stands: no phase is added, no document returns.
