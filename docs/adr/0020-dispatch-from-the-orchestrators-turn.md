# 0020: Dispatch runs from the orchestrator's own turn; the wrapper subagent is retired

Date: 2026-07-25 (recording the decision of 2026-07-23, delivered here after 0.99.0 landed the wrapper shape forward).

Decision: a worker the harness cannot pin natively runs as a CLI call driven from the orchestrator's own turn. `scripts/codex-exec` runs as tracked background Bash from the orchestrator's turn; a chunk the shell ceiling or an interruption cuts short is resumed on its thread (`--resume <thread-id>` from the events file) until a clean exit delivers the report. This supersedes ADR 0008's launch shape (the wrapper subagent). Everything else in 0008 stands: the proxy stays declined, `scripts/codex-exec` stays the single assembly point, the process-group kill and stall watchdog stay, and backgrounding inside a subagent stays fatal (docs/lessons/subagent-background-work-dies-silently.md).

Why: run #524 (nadicodeai, 2026-07-23) broke the wrapper twice in one night, both times identically. A sonnet wrapper, instructed to hold one foreground call and never background it, backgrounded it anyway and ended with a waiting stub while the worker's report sat undelivered (an empty out file beside a 1.1MB events log). The second failure came from a hardened brief that spelled out the whole resume procedure, so instruction text is not the fix: a subagent asked to sit blocking for tens of minutes backgrounds the call, whatever it is told. The same session validated the replacement live end to end: the orchestrator drove the identical commands from its own turn, the harness's tracked background Bash held a visible task row and delivered every completion notification, and resume chaining turned interrupted chunks into finished, verified runs (the plan editor and two builders; slice S1 landed and gate-checked). The panel skill had already dispatched its seats this way without failure. The wrapper existed to give the worker a visible row; a tracked background task is that row.

Recorded limits: chunk length is bounded by the shell timeout ceiling, so an unraised ceiling means more resumes (bottega:setup still raises it); quiet stretches between chunk completions read as a stalled session unless the orchestrator states the rhythm once; the route guard was shaped for subagent dispatches, and its coverage of own-turn shell-outs is a filed followup.
