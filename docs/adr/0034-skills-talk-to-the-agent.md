# Skills talk to the agent doing the work

The owner set the style on 2026-07-28, with the rewritten maestro as the exemplar and the upstream skill-writing doctrine as the ground: a skill's body is written to the agent that will do the work, the way one person briefs a capable colleague. Imperative, "you". Rules live in the sentences where the work happens. A step's finish line is part of the step's own prose, never a trailing "Complete when" formula. Headings appear only where they shorten the read, and are numbered only where the sequence itself is the instruction, a walkthrough someone resumes midway (setup is the one such skill). Semicolons are out of skills prose entirely: each one is two sentences wearing one, so it splits. Code and vendored text keep their own syntax.

This replaces the House format's two-shape mandate ("a method is numbered phases as `## N. Verb` headings, each ending on its completion criterion"). That mandate was bottega's own addition on top of the upstream doctrine, which never required it: upstream lets steps and reference mix freely and asks only that a step's finish line be checkable. The checkable finish line survives, restated in prose. The rest of the upstream doctrine (invocation and the two loads, the information hierarchy, progressive disclosure, the two splits, pruning, leading words, the failure modes) is unchanged.

Applied across every skill in the tree in the same diff, with the register rules ("no semicolons in skills prose", the body-voice rule) added to the working agreement and enforced by the register test.
