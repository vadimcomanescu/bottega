# One orchestrator seat, pins at the dispatch sites

Bottega ran on two interchangeable orchestrator seats (Claude Code or Codex) with a central routing skill holding a model table, task rules, and per-harness reach mechanics. This decided three things at once.

The seat commits to Claude Code on fable-5 at xhigh, and the Codex-orchestrator path is removed. Not for missing capability: Codex closed the primitive gaps in spring 2026 (per-subagent model and effort pins, PreToolUse deny hooks, parallel subagents). The grounds are operational: its own tracker documents subagent lifecycle leaks, freezes, and lost visibility on resume in exactly the hours-long regime a run needs (openai/codex #19197, #34061, #16358), per-dispatch spawn metadata ships disabled, the CLI has no browser for QA, and the field pattern, including OpenAI's own first-party plugin, drives Claude Code with Codex as the dispatched engine, never the reverse. The warm fallback is the exercised codex-exec worker path, not a maintained second seat.

The routing skill is dissolved: each phase skill pins the model and effort for the workers it dispatches, at the dispatch site, and maestro carries the two invariants (fable is the seat and never a worker; no verification seat runs the family that built the diff) plus the one-diagnosed-step escalation rule. Builders move from gpt-5.6-sol to opus-5 at xhigh, dispatched natively; sol remains the cross-family verifier (review engine, review rerun, spec conformance, plan editor, panel seat). Grounds: self-preference and self-attribution studies show review quality drops precisely when the judging family authored the code (arXiv:2504.03846, 2603.04582), family-diverse review has measured headroom (arXiv:2510.21513), and Opus 5 priced at half of Opus 4.8 moved building from a weekly-capped pool to a per-token slope. The plan strengthen loop shrinks to one cross-family editor pass: round one carries the measured diversity benefit; no evidence backs further rounds.

Sonnet leaves the system: every Claude-side worker runs opus-5 with effort as the only cost lever, per Anthropic's Opus 5 effort guidance. Fable-5 stays swappable in one place (the maestro seat line): it is plan-rationed and the priciest tier, so the seat pin must never spread.

Supersedes the routing-skill and cross-harness-seat parts of ADR 0005; the skills-as-method, worker-brief, and codex-exec decisions there stand.
