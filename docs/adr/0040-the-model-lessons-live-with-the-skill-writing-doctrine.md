# 0035: The model lessons live with the skill-writing doctrine

Date: 2026-07-31

The skill-writing doctrine held one line telling the writer to read Anthropic's model-generation guidance from two URLs before setting a rule, and the calibrate skill audited agent docs against a "Claude 5 calibration bar" whose sources were named nowhere. The owner retired calibrate: its cut tests restated the writing doctrine's own no-op and derivable tests, so the audit it performed is a session with the doctrine, not a separate capability. The three sources (the Fable field guide on unknowns, the Claude 5 context-engineering rules, and the Fable 5 prompting page) are now distilled into references bundled inside `skills-internal/write-bottega-skills`, following the reference-bundling practice of the Agent Skills standard and Anthropic's own skills, and the lessons themselves stand in that skill's body, each pointing at its reference for depth. The body's read-the-URLs line and the House rules' two-tests bullet folded into the same section, so the calibration doctrine has one home. Each distill opens with its source URL, and a new model generation means rereading the sources and re-auditing every skill against them.
