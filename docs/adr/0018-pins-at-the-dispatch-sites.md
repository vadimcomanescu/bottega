# Pins at the dispatch sites, two seats held

Bottega selected worker models through a central routing skill: a model table, task rules, and per-harness reach mechanics, invoked before every dispatch. This decided four things.

The routing skill is dissolved: each phase skill pins the model and effort for the workers it dispatches, at the dispatch site, and maestro carries the invariants that bind every pin (fable-5 orchestrates and is never a worker; no verification seat runs the family that built the diff) plus the one-diagnosed-step escalation rule. Three of the old rules were constants owned by other documents, the table carried rows no rule reached, and the pre-dispatch invocation added a hop and a drift surface for a decision each phase already owns.

Builders move to the seat's native family at xhigh (opus-5 under Claude Code, gpt-5.6-sol under Codex), dispatched through the harness's own isolation; the other family keeps every verification seat (review engine, review rerun, spec conformance, plan editor, panel seat). Grounds: self-preference and self-attribution studies show review quality drops precisely when the judging family authored the code (arXiv:2504.03846, 2603.04582), family-diverse review has measured headroom (arXiv:2510.21513), and native dispatch restores ask-back and per-dispatch pinning that a CLI shell-out cannot give the builder role. The plan strengthen loop shrinks to one cross-family editor pass: round one carries the measured diversity benefit; no evidence backs further rounds.

Sonnet leaves the system: workers run the seat's native frontier family with effort as the only cost lever, per the vendors' own effort guidance. Opus 5's launch pricing (half of Opus 4.8) removed the economic case for a lower tier on seats whose errors multiply (exploration feeds the spec, a QA false pass ships a defect).

Both seats stay. Deleting the Codex seat was considered and reworked away: the reliability evidence against it targets Codex's native multi-agent machinery, which bottega's seat barely uses (workers are thin wrappers around foreground CLI calls), per-subagent model overrides landed in Codex 0.145.0, and fable's plan rationing (50% of weekly usage on Max plans) makes the sol seat the path that keeps runs possible when fable is capped. The seat check stops and asks rather than falling back between seats.

Supersedes the routing-skill part of ADR 0005; its cross-harness method, worker briefs, and codex-exec decisions stand.
