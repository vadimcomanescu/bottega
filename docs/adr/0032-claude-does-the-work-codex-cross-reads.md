# Claude does the work; codex only cross-reads finished work

The owner set the boundary: bottega runs on Claude. Codex is dispatched only where the value is another company's eyes on finished work, and only when its CLI is available: the plan editor's cold read (gpt-5.6-sol at high), the integrated review's GPT engine, and the spec-conformance check. It orchestrates nothing and builds nothing. The other roles that named codex convert to Claude workers: the discovery sweep runs on Opus at low effort, and the panel's seats become independent fresh Opus contexts at max effort, blinded and compared as before, since independent runs of one strong model still cover different considerations. When the codex CLI is unavailable, a fresh Opus worker at the same effort takes each codex read under the same contract and the run records the gap; no read is dropped for the CLI's absence.

Grounds: the codex weekly quota is a hard cutoff a run cannot budget against mid-flight, and prose that gave codex standing roles beyond reading kept suggesting codex could act as a second orchestrator. One company everywhere but the cross-reads keeps the run's spend on one metered plan and the orchestration unambiguous.
